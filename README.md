# Lurg Buerano Portfolio

A responsive personal portfolio showcasing frontend-focused projects, web and mobile application work, and contact details.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Accessible dark-mode toggle that remembers the selected theme
- Project cards with previews, technology tags, and GitHub links
- Contact links for email, GitHub, and LinkedIn

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons

## Run locally

This is a static website, so no build process is required. Open `index.html` in a browser, or serve the folder with any local static-file server.

## Project structure

```text
index.html                Main portfolio page
assets/css/portfolio.css  Custom responsive styling
images/                   Project preview images
```
